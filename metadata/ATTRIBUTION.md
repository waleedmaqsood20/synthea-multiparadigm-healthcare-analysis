Per the CSIRO Data Access Portal collection description: an Australianised
version of Synthea was used to generate **117,258 synthetic patients** from
Queensland. Synthea generates data from publicly available population
aggregate statistics (demographics, disease prevalence/incidence, health
reports) and manually curated clinical workflow/disease-progression models.
It does not use real patient data.

**This repository's analysis code and cross-paradigm methodology are the
author's own work, prepared as an academic data analysis project for the
Master of Data Science program at the University of Southern Queensland
(UniSQ). The synthetic dataset itself is CSIRO/Ibrahima Diouf's work, used
